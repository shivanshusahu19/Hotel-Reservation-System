🏨 Hotel Reservation System

A simple Hotel Reservation System developed in Java that allows users to manage hotel room bookings easily through a console-based application.

📌 Project Overview

The Hotel Reservation System is a Java-based project designed to perform basic hotel reservation operations. Users can view available rooms, make reservations, check booking details, and cancel reservations.

✨ Features

- 🏨 View available hotel rooms
- 🛏️ Book a room
- 👤 Enter customer details
- 📋 View reservation details
- ❌ Cancel reservation
- 🔍 Search reservation
- 💰 Calculate room charges
- 📅 Store check-in and check-out details
- 🔐 Simple and user-friendly menu
- 💻 Console-based Java application

🛠️ Technologies Used

- Java
- OOP (Object-Oriented Programming)
- ArrayList / Collections
- Scanner
- Java Date & Time API

🚀 How to Run

1. Download or clone this repository.
